Kconfig · menuconfig · .config

RT-Thread / Linux 系 Kconfig 工作流 — 关系与数据流

Kconfig（通常多个 Kconfig 文件通过 source 拼成一棵树）是配置项的定义：有哪些菜单、选项类型（bool / string / int）、默认值、依赖（depends on）、选中时自动带上的项（select）等。它描述的是「能配什么、怎么合法」，本身不保存你当前工程选了什么。

menuconfig 是人机界面之一：在终端里用菜单勾选/输入，背后仍然按同一套 Kconfig 规则解析与校验。同类还有 nconfig、纯文本的 oldconfig 等；它们都是「前端」，读 Kconfig，改的是结果文件。

.config 是当前配置快照：把每个符号写成 CONFIG_XXX=y、# CONFIG_XXX is not set 或具体取值。构建系统会据此生成头文件（如本工程的 rtconfig.h），编译时 C 代码用宏看到最终开关。

数据流

一句话：Kconfig = 菜谱 · menuconfig = 点菜界面 · .config = 已下单的清单 · rtconfig.h = 厨房用的便签（编译可见）

Kconfig（片段）

config SOC_STM32F446RETX
    bool
    select SOC_SERIES_STM32F4
    default y

.config（片段）

CONFIG_SOC_STM32F446ZE=y
CONFIG_BOARD_STM32F446_NUCLEO=y
# CONFIG_RT_KLIBC_USING_LIBC_VSNPRINTF is not set
